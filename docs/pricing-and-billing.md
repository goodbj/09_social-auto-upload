# YouPick 远程服务 · 报价单与续费钩子

> 卖服务不卖代码：卖的是「远程安装 + 售后 + 客服 + 远程控管」，持续收费。
> 口径：内部结算用；对外报价以合同为准。三档版本见 `product-development-plan.md` 第 2~3 节。

## 一、报价结构（一次性 + 持续）

| 版本 | 一次性安装费 | 月度托管/维护/客服 | SLA / 优先响应 | 续费主收入 |
|---|---|---|---|---|
| **体验版**（引流） | ¥0 / ¥99 尝鲜 | ¥99/月（限制额） | 无 | 引流，靠转标准/至尊 |
| **标准版**（主力成交） | ¥1,980 | ¥999/月 | 工作日工单 24h | ✅ 主收入 |
| **至尊版**（大客/矩阵） | ¥4,980 | ¥2,999/月 | 7×12h 优先 + 专属 | ✅ 主收入（含 SLA） |

- 一次性：远程安装 + 接入配置（含会话登录态注入、人设设定、首轮 demo 跑通）。
- 持续：月度托管（远程控管闭环跑）/ 维护（接口变更适配）/ 客服（客户答疑 + 候选拍板协助）。
- 至尊含：多账号多平台托管 + SLA + 优先响应 + 数据看板。

## 二、续费钩子（产品化、可落地）

1. **到期前 7 天**自动出 `report`（互动量/待拍板候选/健康状态）附续费提醒 → 推送客户。
2. **到期前 3 天**二次提醒；**到期当天**若未续，闭环自动进入 `paused` 状态（停止 run，保留 data/ 不丢数据）。
3. **停服阈值**：逾期 15 天未续 → 标记 `suspended`，后台不再拉起；data/ 目录保留 90 天可恢复。
4. **恢复续费**：补款即 `resume`，data/ 原地接管，历史轮次/动作账完整延续。

## 三、版本升降级（不重写、换配置）

- 体验版 → 标准版 / 至尊版：**换一份 `capabilities` 配置 + 装/卸模块**，不动 core（见计划书 4.0 分层）。
- 降级同理：关开关 + 少装模块，data/ 不变。
- 计费同步：升降级当月按新档计费，次月生效。

## 四、交付物清单（卖给客户拿到手的东西）

- 远程安装 + 跑通的闭环 demo（data/ 一套，含登录态）；
- 接入配置模板（`remote-service-config.md`）；
- 月度 `report`（互动量 + 候选 + 续费状态）；
- 客服通道（答疑 + 候选拍板协助）。

## 五、红线（卖出去也不能破）

- 不碰：验证码绕过 / 设备指纹 / 批量养号 / 刷量。
- 对外发送须老泡儿点头；部署/重启服务端/改库须明确批准。
- 客户数据隔离：data/ 每客户一套，不串、不进公共库；出境走 L3。
